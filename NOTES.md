# Notes

This repository contains the exam client code only. It does not include the full CARLA simulator package, maps, binaries, or Unreal assets.

Expected local setup:

- CARLA 0.9.15 is installed separately.
- The script is run from a machine where the CARLA Python API is available.
- In the original development environment, the launcher used a `carla0915` conda environment.

The full simulator folder was not published because it is very large and contains many third-party binary assets.
